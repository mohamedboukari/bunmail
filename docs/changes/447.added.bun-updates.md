- **Bun stays current (#447).** The Dockerfile's `FROM oven/bun:<version>` lines are now the one source of the Bun version: `ci.yml` and `dependabot-lockfile.yml` read it in a first step (strict `X.Y.Z`, every stage the same, or the job fails) instead of pinning their own. Dependabot's new `docker` ecosystem proposes base image bumps weekly (labelled `skip-changelog`), and a new weekly `bun-canary.yml` workflow runs install, typecheck, unit and e2e on Bun's canary build, opening or updating one `bun-canary` issue on failure. A Bun bump merges only after full CI and a test-server check. Docs: `docs/testing.md` ("Upgrading Bun"), `CONTRIBUTING.md`.
