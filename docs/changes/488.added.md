- **Attach files from the dashboard Send form (#488).** The Send form (and the reply form of an inbound email) has a file input for up to 10 files within `ATTACHMENTS_MAX_TOTAL_MB`, checked by the same rules as a REST send: a blocked type, too many files, too large a total or an invalid filename is refused with its own message instead of a generic one. Inline `cid:` images stay API and SMTP only.
