- **CSV exports neutralise a formula after a line break inside a cell (#451).** A formula character (`=`, `+`, `-`, `@`, after optional spaces, no-break spaces, U+200B or U+FEFF) right after a CR or LF inside a text cell now gets a leading `'`, as after a `;` or tab. Excel in a `;` locale (German, French, Dutch) ignores the quotes and starts a new row at the line break, so an inbound subject such as `Hi\n=HYPERLINK(...);` (or a remote `last_error`, a bounce diagnostic, a DMARC `org_name`) became a live formula in an admin's spreadsheet. The line break is kept, so multi-line values stay intact; every dashboard export goes through the same writer.
