- **The email preview sanitizer also removes MathML, SVG and iframes, and neutralizes any leftover link, meta or base tag (#454).** The preview removed an email's `<link>`, `<meta>`, `<base>` and `<noscript>` elements with Bun's `HTMLRewriter` (#419), but inside MathML or SVG foreign content the rewriter and a browser can disagree on which elements are raw text, so a crafted email could carry one of those elements past the rewriter and have the browser create it (a resource hint is not reliably covered by CSP, so opening the email could reach the sender). `<math>` and `<svg>` elements are now removed with their content (email clients do not render MathML, and most do not render inline SVG), and so is `<iframe>`, whose `srcdoc` is a nested document neither pass reads. After rewriting, any `<link`, `<meta` or `<base` start tag left in the output (in any case, ended by whitespace, `/` or `>`) has its `<` entity-encoded, so a browser can only read it as text; the scan is linear time over the whole output. The meta CSP, the remote-images toggle, the srcdoc encoding and the fail-safe empty preview are unchanged. A previewed email that relied on inline SVG shows without it.
