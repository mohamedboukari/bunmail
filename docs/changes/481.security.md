- **The send log no longer carries the message subject (#481).** The `info` line `Sending email via SMTP` logged each email's subject. A subject is message content, and the inbound notification's subject is `New email for <recipient>`, so the inbound recipient's full address reached the logs even with `LOG_REDACT_PII=true`. The line now logs `subjectLength` instead. A sweep of every other log call found no subject, body, attachment name or header value.
